Linear Equations

CBSE Class 10 • Maths — Chapter 3 • Quick Revision Sheet + PYQs

1. Chapter Formulas & Conditions

General Form: a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0.

Conditions for Consistency / Nature of Lines:
  • Intersecting Lines: a₁/a₂ ≠ b₁/b₂ (Exactly one solution / Unique solution) → Consistent.
  • Coincident Lines: a₁/a₂ = b₁/b₂ = c₁/c₂ (Infinitely many solutions) → Dependent / Consistent.
  • Parallel Lines: a₁/a₂ = b₁/b₂ ≠ c₁/c₂ (No solution) → Inconsistent.

2. Important Concepts

  • Graphical Method: Plot both equations on a graph. The point of intersection gives the solution. If they don't intersect, there is no solution.
  • Algebraic Methods of Solving:
    • Substitution Method: Express one variable in terms of the other from one equation and substitute it in the second equation.
    • Elimination Method: Multiply equations by suitable constants to make the coefficients of one variable equal, then add/subtract to eliminate it.

3. PYQ with Solutions

Very short / MCQ — 1 mark

Q1. For what value of k, do the equations 3x - y + 8 = 0 and 6x - ky = -16 represent coincident lines? CBSE 2019 [1]
Solution: For coincident lines, a₁/a₂ = b₁/b₂ = c₁/c₂.
The second equation is 6x - ky + 16 = 0.
3/6 = -1/-k = 8/16 ⇒ 1/2 = 1/k ⇒ k = 2.

Short answer — 2/3 marks

Q2. Solve the following pair of linear equations by substitution method: x + y = 14; x - y = 4. [2]
Solution: From the second eq, x = y + 4.
Substitute in first eq: (y + 4) + y = 14 ⇒ 2y = 10 ⇒ y = 5.
Then x = 5 + 4 = 9.
Answer: x = 9, y = 5.
Q3. Five years ago, Nuri was thrice as old as Sonu. Ten years later, Nuri will be twice as old as Sonu. How old are Nuri and Sonu? IMPORTANT [3]
Solution: Let Nuri's present age be x and Sonu's be y.
5 yrs ago: (x - 5) = 3(y - 5) ⇒ x - 3y = -10 ... (i)
10 yrs later: (x + 10) = 2(y + 10) ⇒ x - 2y = 10 ... (ii)
Subtract (i) from (ii): (-2y) - (-3y) = 10 - (-10) ⇒ y = 20.
Substitute y = 20 in (ii): x - 40 = 10 ⇒ x = 50.
Nuri is 50 years old and Sonu is 20 years old.

Long answer / HOTS — 5 marks

Q4. The sum of a two-digit number and the number obtained by reversing the digits is 66. If the digits of the number differ by 2, find the number. How many such numbers are there? HOTS [5]
Solution: Let the ten's digit be x and unit's digit be y. Number = 10x + y.
Reversed number = 10y + x.
Given: (10x + y) + (10y + x) = 66 ⇒ 11(x + y) = 66 ⇒ x + y = 6 ... (i)
Also given digits differ by 2, so either x - y = 2 or y - x = 2.
Case 1: x - y = 2 ... (ii). Add (i) and (ii): 2x = 8 ⇒ x = 4. Then y = 2. Number = 42.
Case 2: y - x = 2 ... (iii). Add (i) and (iii): 2y = 8 ⇒ y = 4. Then x = 2. Number = 24.
There are two such numbers: 42 and 24.
