Introduction to Trigonometry

CBSE Class 10 • Maths — Chapter 8 • Quick Revision Sheet + PYQs

1. Chapter Formulas

Trigonometric Ratios (in a right Δ ABC, right angled at B, for angle A):
sin A = Perpendicular / Hypotenuse (P/H)
cos A = Base / Hypotenuse (B/H)
tan A = Perpendicular / Base (P/B)
cosec A = 1/sin A (H/P)
sec A = 1/cos A (H/B)
cot A = 1/tan A (B/P)
Tip to remember: "Some People Have, Curly Brown Hair, Through Proper Brushing"

Trigonometric Identities:
sin² A + cos² A = 1
1 + tan² A = sec² A
1 + cot² A = cosec² A

2. Important Concepts

  • The values of the trigonometric ratios of an angle do not vary with the lengths of the sides of the triangle, if the angle remains the same.
  • Standard Angles Table: You must memorize the values of sin, cos, and tan for 0°, 30°, 45°, 60°, and 90°.
    • sin(30°) = 1/2, sin(45°) = 1/√2, sin(60°) = √3/2
    • cos(30°) = √3/2, cos(45°) = 1/√2, cos(60°) = 1/2
    • tan(30°) = 1/√3, tan(45°) = 1, tan(60°) = √3
  • The value of sin A or cos A never exceeds 1, whereas the value of sec A or cosec A is always greater than or equal to 1.

3. PYQ with Solutions

Very short / MCQ — 1 mark

Q1. If sin A = 3/4, calculate cos A. [1]
Solution: sin A = P/H = 3/4. Let P = 3k, H = 4k.
By Pythagoras, B² = H² - P² = 16k² - 9k² = 7k² ⇒ B = √7k.
cos A = B/H = √7 / 4.

Short answer — 2/3 marks

Q2. Evaluate: 2 tan² 45° + cos² 30° - sin² 60°. CBSE 2019 [2]
Solution: We know tan 45° = 1, cos 30° = √3/2, sin 60° = √3/2.
Expression = 2(1)² + (√3/2)² - (√3/2)² = 2(1) + 3/4 - 3/4 = 2.
Q3. Prove that: (sec A + tan A)(1 - sin A) = cos A. IMPORTANT [3]
Solution: LHS = (1/cos A + sin A/cos A)(1 - sin A)
= [ (1 + sin A) / cos A ] × (1 - sin A)
= (1 - sin² A) / cos A
= cos² A / cos A = cos A = RHS.

Long answer / HOTS — 5 marks

Q4. Prove the identity: (sin A + cosec A)² + (cos A + sec A)² = 7 + tan² A + cot² A. HOTS CBSE 2018 [5]
Solution: LHS = (sin² A + cosec² A + 2 sin A cosec A) + (cos² A + sec² A + 2 cos A sec A)
Since sin A cosec A = 1 and cos A sec A = 1:
= (sin² A + cos² A) + cosec² A + sec² A + 2(1) + 2(1)
= 1 + (1 + cot² A) + (1 + tan² A) + 4
= 1 + 1 + 1 + 4 + cot² A + tan² A
= 7 + tan² A + cot² A = RHS. Hence proved.
