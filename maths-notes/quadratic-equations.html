Quadratic Equations

CBSE Class 10 • Maths — Chapter 4 • Quick Revision Sheet + PYQs

1. Chapter Formulas

Standard Form: ax² + bx + c = 0 (where a ≠ 0)

Quadratic Formula: The roots are given by:
x = [ -b ± √(b² - 4ac) ] / 2a

Discriminant (D): D = b² - 4ac

2. Important Concepts

  • Nature of Roots: Depends on the Discriminant (D = b² - 4ac):
    • D > 0: Two distinct real roots.
    • D = 0: Two equal real roots.
    • D < 0: No real roots.
  • Solving by Factorisation: Split the middle term 'bx' into two parts whose sum is 'b' and product is 'ac'. Then factorise.
  • Word Problems: Framing quadratic equations from real-life situations (like speed-distance, age, areas). Always discard the root that doesn't make sense physically (like negative age or distance).

3. PYQ with Solutions

Very short / MCQ — 1 mark

Q1. Find the value of k for which the quadratic equation 2x² + kx + 3 = 0 has equal roots. CBSE 2019 [1]
Solution: For equal roots, Discriminant D = 0.
b² - 4ac = 0 ⇒ k² - 4(2)(3) = 0 ⇒ k² - 24 = 0 ⇒ k² = 24 ⇒ k = ±2√6.

Short answer — 2/3 marks

Q2. Solve for x: x² - 3x - 10 = 0 by factorisation method. [2]
Solution: Split -3x into -5x and 2x.
x² - 5x + 2x - 10 = 0 ⇒ x(x - 5) + 2(x - 5) = 0
(x - 5)(x + 2) = 0. Therefore, x = 5 or x = -2.
Q3. Find the roots of the equation 2x² - 7x + 3 = 0 using the quadratic formula. [3]
Solution: Here a = 2, b = -7, c = 3.
D = b² - 4ac = (-7)² - 4(2)(3) = 49 - 24 = 25.
x = [-b ± √D] / 2a = [7 ± √25] / 4 = [7 ± 5] / 4.
Roots are (7+5)/4 = 12/4 = 3 and (7-5)/4 = 2/4 = 1/2.

Long answer / HOTS — 5 marks

Q4. A train travels 360 km at a uniform speed. If the speed had been 5 km/h more, it would have taken 1 hour less for the same journey. Find the speed of the train. IMPORTANT CBSE 2020 [5]
Solution: Let the usual speed be x km/h.
Time taken = 360 / x.
If speed is (x + 5) km/h, time taken = 360 / (x + 5).
According to the question: (360 / x) - (360 / (x + 5)) = 1
⇒ 360 [ (x + 5 - x) / x(x + 5) ] = 1
⇒ 360 × 5 = x² + 5x ⇒ x² + 5x - 1800 = 0.
Factorising: x² + 45x - 40x - 1800 = 0 ⇒ x(x + 45) - 40(x + 45) = 0
⇒ (x - 40)(x + 45) = 0.
Since speed cannot be negative, x = 40.
The speed of the train is 40 km/h.
Roots hold the tree, roots hold the equation!
